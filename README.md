# aaa-second-task

# ДЗ: Функции (отчёты по сотрудникам)

Скрипт читает CSV-выгрузку по сотрудникам (`Corp_Summary.csv`) и готовит один из трёх отчётов:
1. **Иерархия** — выводит на экран иерархию департаментов, входящих в них команд и должностей.
2. **Сводка по департаментам** — выводит на экран численность сотрудников, минимальную, максимальную и среднюю зарплату по каждому департаменту.
3. **Сохранение сводки в CSV** — записывает сводную таблицу из пункта 2 в файл `departmental_summary.csv`.

## Требования и зависимости
- **Python 3.8+**
- Внешние библиотеки не требуются: используется только встроенный модуль `csv`.
